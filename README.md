# Hola, universo

Plan de estudio como afición en astronomía, física y matemáticas, publicado como web en GitHub Pages.

- El plan, las decisiones y el flujo de trabajo están en [`PLAN.md`](PLAN.md).
- Las 48 semanas están en [`TEMARIO.md`](TEMARIO.md).
- La web usa [Astro Starlight](https://starlight.astro.build). Los textos están en `src/content/docs/`.

Para verla en local: `npm install` y `npm run dev`.
